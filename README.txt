WHEELIE TRACKER PWA v2

New in v2:
- Live wheelie angle relative to calibrated normal riding angle.
- Maximum angle for the current wheelie.
- Maximum angle for each completed wheelie.
- Highest angle recorded during the ride/session.
- Last wheelie summary now includes maximum angle.

How to use:
1. Host these files on any HTTPS website.
2. Open the site in Safari on the iPhone.
3. Tap START RIDE and allow Motion/Orientation and Location.
4. With the phone firmly mounted to the bike in its normal riding position, tap CALIBRATE NORMAL RIDING ANGLE.
5. Add the site to the iPhone Home Screen if desired.
6. Keep the app open while riding.

Angle explanation:
The app shows angle ABOVE the calibrated normal riding position.
Example: if normal riding is calibrated as 0°, lifting the bike 25° above that position shows about 25°.

Important:
The phone must stay rigidly fixed to the bike for the angle measurement to be meaningful.
